## 🏛️ Project & System Architecture Details

The project is structured as a decoupled monorepo containing three core components:
1. **Customer Web App (public)**: Built with React 19, Vite, and Tailwind CSS.
2. **Owner/Staff Admin Portal (portal)**: Built with React 19, Vite, Tailwind CSS, and Recharts.
3. **Core REST API Backend (server)**: Built with Node.js, Express, Mongoose, Redis, Socket.IO, Razorpay (payment gateway), Cloudinary (CDN storage), Sentry, Opossum, and BullMQ.
